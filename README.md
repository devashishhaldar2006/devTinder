# DevTinder API

The backend for a developer networking and matching platform. It uses Node.js, Express, MongoDB, and JWT-based authentication to support developer profiles and connections.

## Stack

- Node.js and Express
- MongoDB with Mongoose
- JWT authentication
- Password hashing with bcrypt
- Request validation with validator

## Development

```bash
npm install
npm run dev
```

Create a `.env` file for the database connection and authentication configuration required by the application.

> API routes and environment requirements may evolve as the project develops.
